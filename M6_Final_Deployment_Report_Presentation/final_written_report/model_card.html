Traffic Accident Injury Severity Prediction

A prototype tabular classification model that estimates the likely injury severity class from recorded crash context. The model is intended for educational demonstration and exploratory safety analysis, not for emergency triage or automated operational decisions.

Intended Use

The model supports classroom demonstration, exploratory crash-risk review, and scenario comparison in the local web app. It can help users see how crash context such as first crash type, roadway context, weather, lighting, and contributing cause relates to predicted injury severity.

Appropriate

Education, prototype demos, retrospective analysis, model comparison, and discussion of public-safety data risks.

Not Appropriate

Emergency dispatch, real-time triage, legal decisions, insurance decisions, or replacing professional judgement.

Data and Inputs

The project uses 209,275 cleaned traffic accident records after removing 31 exact duplicates from 209,306 raw rows. The final split is stratified: 167,420 training rows and 41,855 test rows.

Traffic control Weather Lighting First crash type Trafficway Road surface Road defect Intersection Contributing cause Units and time

Leakage-prone columns were excluded, including crash_type, damage, injuries_total, injuries_fatal, injuries_incapacitating, injuries_non_incapacitating, injuries_reported_not_evident, and injuries_no_indication.

Target Design

The original five injury labels were compressed into three operational classes to reduce instability from the extremely rare fatal-only class while preserving a severe/fatal signal.

NO_INJURYNo indication of injury
MINOR_INJURYReported/not evident or non-incapacitating injury
SEVERE_INJURYIncapacitating or fatal injury

Interpretation: the selected model is strongest on common no-injury cases. It remains weak on severe injuries, so overall accuracy should not be treated as evidence of deployment readiness.

Limitations

  • Severe injuries are rare, so severe-class precision, recall, and F1 are low.
  • The data contains reported crashes only; reporting patterns may differ from real accident occurrence.
  • Inputs include broad categories such as OTHER, MISSING, and UNABLE TO DETERMINE.
  • The model estimates associations from observational records and does not establish causality.
  • The evaluation uses a random stratified split; temporal and geographic validation are still needed.
  • The local web app lacks production controls such as authentication, monitoring, audit logs, and drift checks.

Primary risk: many actual severe-injury crashes are predicted as no injury or minor injury. Any use that prioritizes emergency response would require stronger recall-focused tuning, external validation, and human oversight.

Recommended Use Conditions

  • Display class probabilities, not only the top predicted label.
  • Report macro F1, balanced accuracy, and severe recall alongside accuracy.
  • Use the model as decision support for exploration, never as a decision maker.
  • Before real deployment, validate across time, location, subgroups, and reporting changes.

Suggested next step: tune severe-injury decision thresholds and evaluate the tradeoff between severe recall and false alarms with a cost-sensitive metric.
