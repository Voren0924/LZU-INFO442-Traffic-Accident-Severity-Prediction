Overview

What the model is for

A tabular classification model estimates whether a crash record is likely to be NO_INJURY, MINOR_INJURY, or SEVERE_INJURY using crash context rather than direct injury outcomes.

Prototype decision support
Test accuracy 0.7250

Overall correctness, inflated by the majority no-injury class.

Macro F1 0.4807

Main test metric because it gives equal weight to each class.

Balanced accuracy 0.4844

Average recall across no injury, minor injury, and severe injury.

Severe recall 0.2321

The central limitation for any high-stakes use.

Intended use

Education, local demo, exploratory analysis, scenario comparison, and stakeholder discussion.

Not intended for

Emergency triage, dispatch decisions, legal or insurance decisions, or replacing human judgement.

Inputs

Traffic control, weather, lighting, crash type, trafficway, surface, defects, intersection status, cause, units, and time.

Risk Review

Where the model fails

The biggest practical risk is false reassurance: many actual severe-injury cases are still assigned to lower-severity classes.

Data imbalance

Severe injuries are only 3.3% of the test set, so the model has limited severe examples.

Reporting bias

The dataset contains reported crashes and may reflect reporting practices as well as crash patterns.

Generalization

Random split evaluation should be extended with temporal, geographic, and subgroup validation.
