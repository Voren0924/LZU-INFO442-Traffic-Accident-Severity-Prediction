# Final Deployment, Report & Presentation

This folder contains the final delivery materials for the traffic accident severity prediction project.

## Folder guide

- `deployment/web_app/` — local web application for the working demo.
- `report/` — final written report, 10–15 pages.
- `presentation/` — 7-minute class presentation slides.
- `model_card/` — one-page model card.
- `demo_video/` — demo video file or video link.

## Run the local web app

```bash
cd deployment/web_app
pip install -r requirements.txt
python server.py
```

Then open the localhost URL shown in the terminal. The default port is 8090.
